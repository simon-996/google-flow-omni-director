# 制作流程

## 接收项目

记录片名、主题或用途、受众、时长、横竖屏、风格、对白语言、素材与账户条件。输入可以是一句话、梗概、全剧本、分镜、图片或返工意见。只有一句创意时，先给带标注的短剧情草案和会影响情节的选项。保留已给出的核心人物关系、关键事件与结局。涉及这些要素的改动等用户确认后再定稿。

用户只需要某一部分时，直接产出相应文件或可复制内容，并用现有信息标注必要假设。几轮聊天中保持项目位置、项目文字策略、锁定资产和确认状态一致。

## 资产制作

每项资产独立选一种模式。同一部片可以混用三种模式。

| 模式 | 做法 |
|---|---|
| 只要生图提示词 | 提取事实，标明建议与未知，确认重要视觉选择后交付提示词。图片状态保持待制作 |
| 直接生图 | 先确认主体、风格和需要锁定的特征。用当前图片工具生成，用户验收后登记正式版本 |
| 按已有参考图生成或编辑 | 先记录图中可见内容与用户要求保留、修改的内容。确认后用图片工具编辑或生成，用户验收后登记 |

- **人物**记录年龄感、脸部特征、肤色、体态、发型、服装、配饰、剧情用途和一致性锚点。主角可用一张横向设定板，包含正、侧、背全身，脸部特写和需要的表情。服装变化独立登记。同一张多格板作为 Flow Ingredients 的表现需试拍，误读时改用当前镜头最相关的单视角。
- **场景**默认一张主参考图，记录已知的门窗、家具、人物与道具的位置关系，以及材质、光源方向、时段、天气和空间纵深。未拍到的区域标未知。镜头必须展示未知区域时再考虑补图。
- **道具**优先处理剧情关键和跨镜重复的物件。登记外观、材质、尺寸或比例、出现镜头、状态变化和是否需要独立参考图。普通背景物可合并进场景说明。

## 分镜与制作顺序

按故事功能拆镜头，逐镜填写起止时间、剪辑用时、生成用时、场景、人物、景别、构图、动作顺序、对白、声音、连续性和风险。有效剪辑长度不得超过对应生成段的可用时长。短插镜可生成至少 3 秒后剪取。加总成片时间并对齐目标时长。人多、动作多或物件交互复杂时，优先拆成可以独立验收的动作。

先试一条影响最大的镜头，例如角色主特写、准确中文对白、跨机位空间或精细交互。定下参考图和制作决策，再批量铺镜。用相同资产版本约束服装、动作方向、视线、轴线、道具位置和光线。人物/场景/道具文字和提示词要彼此一致。

## 回片与返工

检视用户提供的材料，记录镜头/TAKE、时间点、严重程度、可见证据、原因假设、受影响的后续镜头和修复方式。检查人物、场景、道具、动作、构图、闪烁或变形、文字、可听对白、音色、口型和前后衔接。单帧只判断可见内容。无法听到音频、查看完整运动或取得原始时钟时，明确需要哪段材料再核查。

修复方式按问题选择。信息冲突先改提示词，参考误读改参考图，动作过载则拆镜或简化，精确文字或对白交后期。保留原分镜和已确认资产，收到替换确认后才调整有效版本。回片重生成但提示词不变时只升 TAKE，提示词文本或生成配置有实质变化时升该镜提示词版本。
